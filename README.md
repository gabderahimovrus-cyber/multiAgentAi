# Multi-Agent AI Studio

Локальное Windows-приложение на Python для работы с автономными ИИ-агентами через Ollama. Интерфейс по умолчанию полностью русскоязычный и построен так, чтобы позже добавлять другие языки, провайдеры моделей и плагины без переработки ядра.

## Запуск

1. Установите Python 3.11+.
2. Установите и запустите Ollama: `ollama serve`.
3. Скачайте хотя бы одну модель, например: `ollama pull llama3.1`.
4. Запустите приложение:

```bash
python main.py
```

Также доступен альтернативный вход:

```bash
python app.py
```

## Возможности текущей минимальной версии

- Современный desktop UI на `tkinter/ttk` с левой панелью чатов, проектов и агентов, центральным чатом, правой панелью настроек и нижней панелью логов.
- Русский интерфейс и каталог строк для будущей локализации.
- Светлая и тёмная темы, изменяемые панели, ввод по Enter и Shift+Enter для переноса строки.
- Автообнаружение локальных моделей Ollama через `/api/tags`.
- Отдельные агенты с именем, ролью, системным промптом, моделью, температурой, памятью, рабочей папкой и разрешениями.
- Создание, удаление, клонирование, включение и отключение агентов.
- Сохранение сообщений, агентов, проектов, задач, памяти, настроек, логов и плагинов в SQLite.
- Рабочие папки агентов и проектов в `~/MultiAgentAIStudio` или в `MULTIAGENT_AI_STUDIO_HOME`.
- Внутренняя шина сообщений между агентами.
- Система задач со Start, Resume, Pause и Stop для управления состоянием системы агентов.
- Панель логов с фильтром и экспортом.
- Экспорт истории чата и полная очистка текущей сессии вместе с логами.
- Заготовки для плагинов, предложений изменений, Git/скриптовых разрешений, векторной памяти/RAG и дополнительных провайдеров моделей.

## Архитектура

```text
multiagent_ai_studio/
  app.py                  # сборка зависимостей и запуск UI
  core/                   # ядро: агенты, БД, память, задачи, плагины, файлы
  providers/              # реестр провайдеров и Ollama provider
  ui/                     # desktop UI
  i18n/                   # русская локализация и будущие языки
main.py                   # основной вход
app.py                    # альтернативный вход
```

Провайдеры моделей подключаются через `ProviderRegistry`. Для OpenAI, Anthropic, Groq или других API достаточно добавить класс с методами `list_models()` и `generate()` и зарегистрировать его в реестре.

## Безопасность

Опасные операции отделены разрешениями агента: выполнение скриптов, доступ к сети и браузеру, запись в Git, создание/удаление агентов и загрузка плагинов. Самомодификация ядра запрещена: агент должен создавать предложение изменения с diff, а пользователь применяет его вручную после просмотра.
